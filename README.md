# Restaurant Page

A simple multi-page restaurant website built entirely with JavaScript. All content is dynamically rendered using DOM manipulation - no hardcoded HTML beyond the initial skeleton.

This project was built as part of [The Odin Project](https://www.theodinproject.com/) curriculum to practice modular JavaScript, the module pattern, and Webpack configuration.

## Features

- Fully modular JavaScript architecture
- Webpack bundled project
- Dynamic DOM rendering (no HTML in the body tag)
- Tab-based navigation (Home, Menu, Contact)
- CSS styling in a separate file
- Deployed via GitHub Pages

## How to run locally

1. Run these commands:

```bash
git clone https://github.com/yourusername/restaurant-page.git
cd restaurant-page
npm install
npx webpack serve
```

2. Open http://localhost:8080 in your browser.
